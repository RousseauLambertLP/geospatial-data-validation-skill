# Team skill review checklist

- [ ] Clear and narrow purpose and invocation trigger
- [ ] No unnecessary overlap with existing team skills
- [ ] Valid SKILL.md YAML frontmatter
- [ ] Explicit inputs, outputs, limitations and escalation
- [ ] Vendor-neutral core instructions
- [ ] No absolute machine-specific paths or embedded credentials
- [ ] References and scripts have valid relative paths
- [ ] Optional dependencies and permissions documented
- [ ] Deterministic tasks delegated to scripts/tests
- [ ] At least one positive, negative and missing-tool evaluation scenario
- [ ] Evaluations actually run and findings recorded
- [ ] Human reviewer approves before team adoption

Review result: APPROVE / REQUEST_CHANGES / REJECT.
Do not reduce this review to an ungrounded numeric score.
